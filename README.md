# Real-Time Chat (Socket.IO + React)

A simple real-time chat application built to explore **WebSocket communication** using **Socket.IO** with a **Node.js backend** and a **React frontend**.

## Features

- Real-time messaging with WebSockets
- User registration (username attached to socket connection)
- Event-driven communication (`user:register`, `chat:message`)
- Server-side message broadcasting

## Tech Stack

- **Backend:** Node.js, Express, Socket.IO  
- **Frontend:** React, socket.io-client  

## Purpose

This project was created as a learning exercise to understand how **real-time systems work**, including socket connections, event-based communication, and associating users with WebSocket sessions.
